# OgrChatAi

### Приватный ИИ-чат и голосовой собеседник прямо на Android

**Модели, речь и память работают на устройстве. Без облака, аккаунтов и телеметрии.**

</div>

---

## О проекте

OgrChatAi — нативное Android-приложение для запуска GGUF-моделей из
[HuggingFace](https://huggingface.co) локально. После загрузки модели чат,
голосовой ввод, озвучивание ответов и работа с файлами не требуют интернета.
Приложение не отправляет сообщения, аудио или историю чатов на внешние серверы.

Проект распространяется по [Apache License 2.0](LICENSE).

### Чем отличается

| | Облачные ИИ-ассистенты | OgrChatAi |
|---|---|---|
| **Приватность** | Сообщения уходят на сервер | Всё считается на устройстве |
| **Офлайн** | Нужен интернет | Работает без сети после загрузки |
| **Голос** | Облачный TTS/STT | Нейроголос Supertonic 3 или системный TTS |
| **История** | Хранится у провайдера | Шифруется и хранится локально |
| **Память** | Управляется сервисом | Сжатый контекст с возможностью очистки |

## Возможности

- **Локальная инференция GGUF** через llama.cpp-обёртку AIKit.
- **Потоковые ответы** с отдельной панелью рассуждений.
- **Голосовые вызовы**: распознавание речи → локальная модель → озвучивание.
- **Нейронная речь Supertonic 3** через sherpa-onnx: 10 выразительных голосов
  (5 женских и 5 мужских), эмоциональные теги `<laugh>`, `<breath>`, `<sigh>`.
- **Гибридный TTS**: нейродвижок при наличии модели, прозрачный откат на
  системный Android TTS.
- **Автоопределение языка речи** для английского, русского, испанского,
  французского и немецкого — отдельно для каждого предложения.
- **Умный контекст**: недавние реплики сохраняются дословно, важные старые
  факты подтягиваются по релевантности, остальное сжимается в краткую память.
- **Очистка памяти без удаления сообщений** — модель забывает прошлое, а чат
  остаётся читаемым.
- **Режим рассуждений для каждой модели**: `Auto`, `On`, `Off`. Для Qwen3
  используются `/think` и `/no_think`.
- **Размер контекста**: 2048, 4096 или 8192 токенов. Жёсткий предел движка —
  8192.
- **Файлы и изображения**: текст и документы передаются модели, изображения
  обрабатываются с учётом возможностей текстовой модели.
- **Локальная история**: Room + шифрование сообщений через Android Keystore.
- **Material 3**, тёмная и светлая темы, адаптивный интерфейс.
- **Без телеметрии, рекламы и аккаунтов.**

## Нейронный голос

Supertonic 3 не входит в APK. Модель скачивается по запросу из настроек
(около 123 МБ в архиве, примерно 300 МБ после распаковки) и хранится в
приватном каталоге приложения. После установки пакета сеть для синтеза речи не
нужна.

- 10 голосов: `F1–F5` и `M1–M5`, с именами и описаниями в выпадающем списке.
- Языки: английский, русский, испанский, французский, немецкий.
- Язык определяется автоматически по каждому предложению.
- При отсутствии модели или ошибке синтеза используется системный TTS.
- Режим `System speech engine` принудительно выбирает системный движок.

Языковые пакеты системного TTS зависят от устройства. Если для языка не
установлены голосовые данные, приложение сообщит об этом в настройках.

Веса Supertonic 3 распространяются по лицензии OpenRAIL-M, пример кода — по
MIT. Ссылки и условия приведены в
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

## Умный контекст и память

Движок хранит диалог в KV-кэше и отправляет только новую реплику пользователя.
Это ускоряет генерацию и не раздувает промпт.

Когда кэш приближается к лимиту, при переключении чата или после очистки памяти
приложение собирает сжатый контекст:

1. **Свежие сообщения** остаются дословно.
2. **Релевантные старые реплики** подбираются по лексическому совпадению.
3. **Память** хранит важные факты, имена, планы, числа и предпочтения в виде
   коротких заметок.
4. **Шумные сообщения** вроде «ок», «спасибо» и «понял» отбрасываются.

Старые темы постепенно затухают, если к ним не возвращаются. Кнопка
**Clear memory** в меню чата задаёт временную границу: прошлые сообщения
остаются в интерфейсе, но больше не попадают в промпт.

Размер контекста ограничен 8192 токенами, чтобы не превысить возможности
движка и не вызвать переполнение.

## Стек

Kotlin · Jetpack Compose · Material 3 · MVVM · Clean Architecture · Hilt ·
Room · DataStore · Retrofit · Coil · llama.cpp через android-ai-kit ·
sherpa-onnx · Supertonic 3.

```
com.ogrchatai.app/
├── data/
│   ├── local/        Room, DAO, миграции
│   ├── remote/       HuggingFace API
│   ├── ml/           inference и KV-кэш
│   ├── tts/          Supertonic 3 и загрузка модели
│   └── preferences/  DataStore
├── domain/           модели, репозитории, use cases
├── ui/               Compose-экраны и ViewModel
├── util/             контекст, TTS-языки, токены, голосовой ввод
└── di/               Hilt
```

## Сборка и запуск

### Требования

- Android Studio с поддержкой AGP проекта
- JDK 17
- Android SDK 37 (`compileSdk = 37`)
- Android 11+ (`minSdk = 30`)
- Для сборки TTS: AAR `app/libs/sherpa-onnx-2.0.1-min.aar` уже в репозитории

### Debug-сборка

```bash
git clone https://github.com/moongrail/OgrChatAi.git
cd OgrChatAi
./gradlew assembleDebug
adb install app/build/outputs/apk/debug/app-debug.apk
```

### Тесты

```bash
./gradlew :app:testDebugUnitTest
```

Покрываются автоопределение языка речи и сборка сжатого контекста:
релевантность, очистка памяти, фильтрация шума и лимит токенов.

## Модели

Поддерживаются GGUF-модели с HuggingFace. Небольшие инструктивные модели
(0.5–3B) комфортно работают на современных телефонах; размер контекста и
скорость зависят от памяти устройства и квантования.

| Модель | Размер | Комментарий |
|---|---:|---|
| Qwen2.5 0.5B Instruct | ~400–500 МБ | Быстрый тест и слабые устройства |
| Qwen3 0.6B / 1.7B | ~0.5–1.2 ГБ | Режим рассуждений `/think` |
| Llama 3.2 1B / 3B | ~0.8–2 ГБ | Хороший баланс |
| Gemma 2 2B | ~1.5 ГБ | Лёгкая и быстрая |
| Phi-3 Mini | ~2.3 ГБ | Более качественные ответы |

Приложение не включает веса моделей. Скачивая модель, вы принимаете её
лицензию.

## Ограничения

- Скорость генерации и TTS зависит от CPU, RAM и квантования модели.
- Голосовой вызов требует микрофон и разрешение `RECORD_AUDIO`; на эмуляторе
  без реального микрофона полноценный сценарий проверить нельзя.
- Системный TTS может не иметь установленных голосов для выбранного языка.
- AIKit сейчас передаёт в llama.cpp ограниченный набор параметров: температура
  и лимит токенов применяются, часть остальных настроек хранится для совместимости.
- Максимальный контекст — 8192 токена.
